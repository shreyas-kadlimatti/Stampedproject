# AI-Based Stampede Prediction and Crowd Density Estimation using CSRNet

## Project Overview

This project aims to estimate crowd density and crowd count from a single image using a deep learning approach. Instead of detecting each individual person, the model predicts a density map whose pixel sum represents the estimated number of people present in the scene.

The project is based on the **CSRNet (Congested Scene Recognition Network)** architecture and uses the **ShanghaiTech Part A** dataset for training and evaluation.

# Work Completed

## 1. Dataset Preparation

- Downloaded ShanghaiTech Part A Dataset.
- Organized training and testing directories.
- Parsed annotation (`.mat`) files containing head coordinates.

---

## 2. Geometry-Adaptive Density Map Generation

Implemented geometry-adaptive Gaussian kernels for density map generation.

### Improvements

- KD-Tree based nearest-neighbor distance computation.
- Adaptive Gaussian sigma for each annotated head.
- Preserved total crowd count by normalizing density maps.
- Density map sum equals the actual ground truth count.

---

## 3. Data Augmentation

Implemented data augmentation to improve model generalization.

Current augmentations include:

- Horizontal Flip
- Brightness Adjustment
- Contrast Adjustment
- Gaussian Noise

---

## 4. Image Preprocessing

Implemented ImageNet normalization to match the pretrained VGG16 feature extractor.

Normalization:

```
Mean = [0.485, 0.456, 0.406]

Std  = [0.229, 0.224, 0.225]
```

---

## 5. CSRNet Architecture

Implemented CSRNet consisting of:

### Frontend

- Pretrained VGG16 convolutional layers
- Feature extraction

### Backend

- Dilated convolution layers
- High-resolution density estimation

---

## 6. Loss Function

Implemented a combined loss function consisting of:

### Density Loss

- Mean Squared Error (MSE)

### Count Loss

- Smooth L1 Loss

This improves both:

- Pixel-wise density estimation
- Overall crowd count prediction

---

## 7. Training Pipeline

Implemented:

- Mixed Precision Training (AMP)
- Adam Optimizer
- Gradient Clipping
- Validation Split
- Learning Rate Scheduler
- Automatic Checkpoint Saving

Saved checkpoints include:

- latest model
- best model
- epoch checkpoints
- final trained model

---

## 8. Prediction Pipeline

Implemented inference pipeline capable of:

- Loading trained model
- Predicting density maps
- Estimating crowd count
- Visualizing predictions

---

## 9. Evaluation Pipeline

Implemented evaluation metrics:

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
