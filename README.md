# AI-Based Predictive Crowd Monitoring & Stampede Prevention System

## Project Setup

### Clone Repository

```bash
git clone https://github.com/shreyas-kadlimatti/Stampedproject.git
```

---

## Create Virtual Environment

### Mac/Linux

```bash
python3 -m venv venv
```

Activate venv:

```bash
source venv/bin/activate
```

---

### Windows

```bash
python -m venv venv
```

Activate venv:

```bash
venv\Scripts\activate
```

---

## Install Requirements

```bash
pip install -r requirements.txt
```

---

# Git Workflow

## Check Current Branch

```bash
git branch
```

---

## Create New Branch

```bash
git checkout -b branch-name
```

Example:

```bash
git checkout -b shreyas-dev
```

---

## Switch Branch

```bash
git checkout main
```

---

## Pull Latest Changes

```bash
git pull origin main
```

---

## Push Changes

```bash
git add .
git commit -m "your message"
git push
```

---

# Virtual Environment Commands

## Exit Virtual Environment

```bash
deactivate
```

---

## Enter Virtual Environment Again

### Mac/Linux

```bash
source venv/bin/activate
```

### Windows

```bash
venv\Scripts\activate
```

---

# Important Notes

- Do NOT push datasets
- Do NOT push venv
- Always pull latest changes before starting work
